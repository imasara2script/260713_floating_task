# バックアップ復元時のプレビューと部分復元の実装完了

バックアップファイルを復元する際、内容を確認し、復元したい項目を個別に選択できる機能を追加しました。

## 変更内容

### [Web UI (assets/index.html)]

- **復元プレビューダイアログの導入**:
    - ファイル選択後、即座に反映するのではなく、内容を一覧表示するプレビュー画面を表示するようにしました。
    - **タスク一覧**: 含まれるタスク名をリスト表示します。
    - **完了履歴**: 件数と期間（最古〜最新）のサマリーを表示します。
    - **ウィンドウ設定**: 倍率やサイズを表示します。
    - **配色ルール**: 設定されているルールと色見本を表示します。
- **部分復元機能**:
    - 各セクションにチェックボックスを追加し、特定の項目（例：設定のみ、タスクのみ等）だけを復元できるようにしました。
- **UI/UXの改善**:
    - ダイアログが長い場合に備えてスクロール機能を追加しました。
    - プレビュー内で実際の色（色見本）を表示し、直感的に内容を把握できるようにしました。

## 検証結果

### 手動確認
- 復元ボタンからバックアップファイルを選択し、プレビューダイアログが表示されることを確認しました。
- 履歴のサマリー形式（件数：開始日時 ～ 終了日時）が正しく表示されることを確認しました。
- チェックを入れた項目のみが LocalStorage に反映され、リロード後に正しく適用されることを確認しました。
