# バックアップ復元時のプレビュー表示と部分復元機能の実装計画

バックアップファイルを復元する際、内容を誤って上書きしてしまうのを防ぐため、反映前に内容をプレビュー表示し、さらに**復元したい項目を選択（部分復元）**できる機能を追加します。

## ユーザーレビューが必要な事項

> [!IMPORTANT]
> 復元内容が多い場合、ダイアログが画面からはみ出す可能性があるため、ダイアログにスクロール機能を追加します。また、履歴が大量にある場合は件数と期間のサマリーを表示します。

## Proposed Changes

### [Web UI (assets/index.html)]

#### [MODIFY] [index.html](file:///C:/Users/tk6479/AndroidStudioProjects/floatingtask/app/src/main/assets/index.html)

- **CSSの修正**:
    - `.modal-content` に `max-height: 85vh;`, `overflow-y: auto;`, `width: 90%;`, `max-width: 450px;` を追加し、選択項目が並んでも見やすいように調整します。
    - プレビュー内のリストやチェックボックス用のスタイルを追加します。
- **showModal関数の修正**:
    - `titleEl.textContent = title;` を `titleEl.innerHTML = title;` に変更し、HTML（チェックボックスや色見本）を表示できるようにします。
- **applyRestoredData関数の修正**:
    - ファイル選択後、データを解析して「タスク一覧」「完了履歴」「カレンダーのマーク」「フローティングウィンドウの設定」「配色ルール」の各セクションをチェックボックス付きでプレビュー表示します。
    - **履歴の表示**: 「〇件：〇〇〇〇年〇〇月〇〇日　〇〇時〇〇分〇〇秒～〇〇〇〇年〇〇月〇〇日　〇〇時〇〇分〇〇秒」の形式でサマリーを表示します。
    - `showModal` の `onConfirm` 内で、チェックが入っている項目のみを抽出し、既存の設定を上書きするようにロジックを修正します。
- **performRestore関数の抽出**:
    - 選択されたフラグに基づいて、LocalStorageを更新しアプリをリロードするロジックを実装します。

## Verification Plan

### Manual Verification
- 設定画面から「復元」ボタンを押し、バックアップJSONファイルを選択する。
- 復元プレビューダイアログが表示され、各項目にチェックボックスが付いていることを確認する。
- 特定の項目（例：「タスク一覧」のみ）のチェックを外して「OK」を押し、その項目以外が正しく復元されるか確認する。
- 「配色ルール」などの詳細項目で、色見本が表示されているか確認する。
- 全てのチェックを外した状態で「OK」を押した場合、何も変更されない（または警告が出る）ことを確認する。
