# タスクインポート機能の改善（個別タスク選択）

「タスクをインポート」機能において、ファイル内のタスクを一覧表示し、ユーザーがインポートしたいタスクを個別に選択できるようにします。

## ユーザーレビューが必要な事項

- **UIの変更**:
    - インポート時のプレビュー画面で、各タスクの横にチェックボックスを表示します。
    - 全選択/全解除ができるように、ヘッダーのチェックボックスと連動させます。
- **復元機能との整合性**:
    - 「復元（上書き）」機能でも同様の個別選択を可能にするか、あるいは現状通り一括のみとするか。今回は「インポート」ボタンからの導線において個別選択を優先的に実装します。

## 変更内容

### [index.html](file:///C:/Users/tk6479/AndroidStudioProjects/floatingtask/app/src/main/assets/index.html)

- **スクリプトの修正**:
    - `applyRestoredData`:
        - `isImportMode` が真の場合、タスク一覧をチェックボックス付きのリストとして描画します。
        - 全選択/全解除のための `toggleAllImportTasks(checked)` 関数を定義します。
    - `performRestore`:
        - `isImportMode` が真かつ個別選択されている場合、選択されたタスクのみをフィルタリングして既存リストに追加します。

## 検証プラン

### 手動確認
1.  タスクが複数含まれるバックアップファイルを用意する。
2.  「タスクをインポート」を実行し、プレビュー画面でタスクが個別にチェックできることを確認する。
3.  一部のタスクのチェックを外し、「OK」を押す。
4.  チェックを入れたタスクのみが現在のリストに追加され、外したものは追加されないことを確認する。
