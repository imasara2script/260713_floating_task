# タスクインポート機能の改善（個別タスク選択対応）

「タスクをインポート」機能において、既存データへの追加マージに加え、ファイル内のタスクを個別に選択してインポートできる機能を追加しました。

## 変更のポイント

### 1. タスクの個別選択 UI
インポート時のプレビュー画面で、各タスクの横にチェックボックスを表示するようにしました。ユーザーは必要なタスクだけを選んでインポートできます。
- **全選択/全解除**: ヘッダーの「タスク一覧」チェックボックスで一括操作が可能です。
- **スクロール対応**: タスク数が多い場合でも、プレビュー領域内でスクロールして確認できます。

### 2. インポート処理の柔軟化
選択されたタスクのみをフィルタリングし、既存のリストに追加するロジックを実装しました。
- **バグ修正**: 以前はヘッダーの「タスク一覧」チェックボックスがオフだと、個別にタスクを選択していてもインポートがスキップされる問題がありましたが、インポートモードでは個別選択を優先するように修正しました。
- **UI改善**: 個別タスクの選択状態に合わせて、ヘッダーのチェックボックスが自動的に「一部選択（不定）」や「未選択」に更新されるようにしました。
- **正確な件数表示**: インポート完了メッセージに、実際に選択したタスクの件数が正確に表示されます。
- **履歴の重複排除**: 完了履歴をインポートする際、既存の履歴と内容（タスク名および完了日時）が完全に一致するエントリーを自動的にスキップするようにし、データが二重に登録されるのを防ぐようにしました。
- **エクスポート形式への対応**: 「タスクをエクスポート」で出力したファイル（部分タスク形式）を読み込んだ際も、バックアップファイルと同様にプレビュー画面が表示され、タスクを個別に選択してインポートできるようになりました。

### 3. 復元機能との棲み分け
「復元」機能では、従来通りバックアップ時の状態を正確に再現するため、タスクの個別選択ではなく一括での上書き動作を維持しています。
