# 展開表示モードの設定項目「表示するタスク数」と「△」ボタンの追加

フローティングウィンドウの展開表示モードにおいて、表示するタスク数を変更できる機能と、ナビゲーション用の「△」ボタンを追加しました。

## 変更内容

### 1. 設定項目の追加
- 展開表示モードの設定セクションに**「表示するタスク数」**（1〜10）の入力項目を追加しました。
- 展開表示モードの設定セクションに**「移動するタスク数」**（1〜10）の入力項目を追加しました。
- 入力欄の横に数値を調整するための**「+」「-」ボタン**を追加し、操作性を向上させました。
- これらの設定は `SharedPreferences` および `localStorage` に保存され、バックアップ/復元機能にも対応しています。

### 2. UI の更新
- **複数タスク表示**: 設定されたタスク数に応じて、展開表示モードで複数のタスクをリスト形式で表示するようにしました。
- **タスク項目のレイアウト変更**: タイマー付きタスクの表示順を「チェックボックス」「残り時間」「リピートボタン」「タイトル」の順に変更しました。
- **「△」ボタン**: 表示するタスク数が 2 以上の場合、前のタスクに戻るための「△」ボタンを表示するようにしました。
- **カウンタ表示**: 複数表示時は `(開始番号-終了番号/全件数)` の形式で現在の表示範囲を表示するようにしました。

### 3. ロジックの更新
- `prevTask()` 関数と `nextTask()` 関数を更新し、`scrollTaskCount` に基づいて指定された数だけタスクを移動するようにしました。
- **移動数の制限**: `scrollTaskCount` の最大値を `displayTaskCount` と一致するように制限しました。`displayTaskCount` を減らした際、`scrollTaskCount` がそれを上回る場合は自動的に調整されます。
- JavaScript ブリッジ (`updateFloatingSettingsExtended`) を更新し、新設定を Android ネイティブ側に渡して保存するようにしました。
- 設定変更時にネイティブ側から `displayTaskCount` および `scrollTaskCount` を明示的に WebView へ渡すようにし、プレビュー表示の同期ラグを解消しました。

## 検証結果

### ビルド確認
- `app:assembleDebug` は正常に終了しました。

### 手動確認項目（ユーザー様へのお願い）
1. 設定画面 -> フローティングウィンドウの設定 -> 展開表示モードの設定 で「表示するタスク数」を変更できることを確認してください。
2. タスク数を 2 以上に設定し、展開表示モードで複数のタスクが表示されること、および「△」ボタンが表示されることを確認してください。
3. 「△」および「▽」ボタンでタスクの表示範囲が切り替わることを確認してください。
4. 設定を保存した後、アプリを再起動しても設定が維持されていることを確認してください。
