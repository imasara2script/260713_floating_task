## 動作確認のお願い

以下の手順で追加の修正を確認してください。

1. **単一のモーダル**: タスクをタップして詳細画面を開き、バックボタンで閉じられることを確認。
2. **モーダルの重なり**:
    - タスク詳細を開く -> 「🗑️（削除）」をタップして確認ダイアログ（カスタムモーダル）を出す。
    - バックボタンを押す -> **確認ダイアログのみが閉じる**ことを確認。
    - 再度バックボタンを押す -> **タスク詳細画面が閉じる**ことを確認。
3. **エクスポート/削除モード**:
    - リスト右上の「リストを編集」->「📤 タスクをエクスポート」を選択。
    - タスク選択画面（青色のパネルが表示されている状態）でバックボタンを押す。
    - **期待値**: エクスポートがキャンセルされ、通常のタスク一覧に戻る。
    - ※「🗑️ まとめて削除」の状態でも同様にバックボタンでキャンセルされることを確認。
4. **設定画面**: フローティング設定詳細を開いた状態でバックボタンを押し、設定メインに戻ることを確認。

## 動作確認のお願い

以下の手順で修正が正しく反映されているか確認をお願いします。

1. アプリを起動し、「設定」タブを開く。
2. 「フローティングウィンドウの設定」ボタンをタップして詳細画面を開く。
3. Androidのバックボタン（◁）を押す。
    - **期待値**: 詳細画面が閉じ、設定タブのメイン画面に戻る。アプリは終了しない。
4. 設定タブのメイン画面で再度バックボタンを押す。
    - **期待値**: アプリが通常通りバックグラウンドに移動する。
