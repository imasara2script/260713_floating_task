# フローティングウィンドウ展開表示モードのレイアウト変更完了

フローティングウィンドウの展開表示モードにおいて、タスク名の表示エリアを広げるためのレイアウト変更を実施しました。

## 変更内容の概要

1.  **ヘッダー行の新設**: 「Floating task」ラベルと操作ボタン（表示切替、ページ送り、ホーム）を上部の１行にまとめました。これにより、タスク表示エリアが横幅いっぱいに使えるようになりました。
2.  **タスクリストの配置変更**: ヘッダーの下にタスクリストを表示する２段構成に変更しました。
3.  **ドラッグハンドルの調整**: ネイティブ側（`FloatingWindowService.kt`）の設定を修正し、新しく設けた上部ヘッダー部分をドラッグしてウィンドウを移動できるようにしました。

## 修正ファイル

### [Floating Task App]

#### [MODIFY] [index.html](file:///C:/Users/tk6479/AndroidStudioProjects/floatingtask/app/src/main/assets/index.html)
- 展開モードの HTML 構造を縦並び（`flex-direction: column`）に変更し、`render()` 関数でヘッダーとタスクリストを分けて描画するように修正しました。
- 「一時的に閉じるボタン」が表示される設定の場合、ヘッダー右側にパディングを追加してボタンの重なりを解消しました。

- タスク数のカウンタをドラッグ可能領域から除外し、右側のボタン類と同じ非ドラッグ領域に移動しました。

#### [MODIFY] [FloatingWindowService.kt](file:///C:/Users/tk6479/AndroidStudioProjects/floatingtask/app/src/main/java/com/example/floatingtask/FloatingWindowService.kt)
- 展開モード時のドラッグハンドルの幅を、カウンタとボタンの両方を含んだ非ドラッグ領域（約210-260dp）を除いた範囲に調整しました。
