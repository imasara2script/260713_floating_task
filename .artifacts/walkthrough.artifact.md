# ウォークスルー - 広告視聴・コイン使用選択モーダルの新レイアウト実装

「広告を視聴するかコインを使用するか」を選択する問い合わせモーダルのレイアウトを、ご提示いただいた添付画像のデザイン（上部説明文、大きな角丸カードボタン2つとアイコン、下部キャンセルボタン）に刷新しました。

## 変更内容

### JavaScript (`modal-manager.js`)
- **`showModal` の拡張**:
  - モーダルに `neutralText`（広告視聴）と `confirmText`（コイン使用）の両方が選択肢として提供されている場合、従来の標準ボタンの代わりに **横並びの大きな角丸カードボタン（アイコンSVG付き）** を動的にレンダリングするようにしました。
  - 左側に「ビデオアイコン ＋ 広告視聴」、右側に「コインアイコン ＋ コイン使用」のカードを配置し、ホバーエフェクトやクリック時のアクション（`onNeutral` / `onConfirm`）を正しく結び付けました。
  - モールが閉じられた際には動的生成されたカードコンテナが自動でクリーンアップ（削除）されるように実装しました。
