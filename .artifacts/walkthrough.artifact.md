# ウォークスルー - タスク毎のオーディオ属性選択肢への「デフォルト」追加

タスク毎のオーディオ属性選択 (`per_task` モード) において、選択肢に「デフォルト」を追加し、「デフォルト」が選択されている場合はメロディ設定画面で指定されている共通のオーディオ属性の設定に従うように実装しました。

## 変更内容

### 1. 翻訳データの追加 (`translations.js`)
- `audio_attr_default`（日本語: `"デフォルト (設定に従う)"`, 英語: `"Default (Follow Settings)"`）の翻訳文字列を追加しました。

### 2. UI の追加 (`index.html`)
- タスク追加・編集モーダルのオーディオ属性セレクトボックス（`taskAudioAttribute`）の先頭に「デフォルト」オプションを追加しました。

### 3. フォールバック判定ロジックの改善 (`app.js` & `modal-manager.js`)
- **`app.js` (`getEffectiveAudioAttribute`)**:
  - `per_task` モード時、タスクのオーディオ属性が設定されていない、または `"default"` である場合、自動的に設定画面の共通設定（`melodyAudioAttribute`）にフォールバックして返すように実装しました。
- **`modal-manager.js`**:
  - タスクの新規作成時および編集時のオーディオ属性の初期値・反映ロジックを「デフォルト」に対応させました。
